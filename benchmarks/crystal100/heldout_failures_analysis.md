# Held-out failure analysis (156 cases) - working report

Status: **analysis complete, fixes implemented and re-evaluated**
(2026-08-12). The held-out benchmark numbers in `results_heldout.md` are
frozen (code-freeze discipline: fixes land in clearly-separated follow-up
commits and are never re-measured into the published numbers). The fix run
is a NEW labeled run: `results_heldout_fix.md` (+ per-bucket sidecars
`results_dataset_heldout_fix_*_k*.json` / `results_stereo_...`). See the
"Fix implementation" section below for the resolution status of each bug
family and the remaining data limitations.

Question answered: of the 156 geometry-tier failures on the held-out set
(600 entries, 5 buckets x 60 per tier), are they bugs or per-case tuning
tweaks? Answer: a mix - **~45 genuine perception bugs (5 families), ~40
threshold-boundary (one shared set of global cutoffs, each miss 0.001-0.05 A),
~55 coordinate-bound (the deposit contradicts the CCD - the benchmark's
intrinsic floor), 12 H-only tautomers, 4 out-of-scope metals.**

## Fix implementation and re-evaluation (2026-08-12)

All 5 bug families fixed in `src/bope` (separate commits, one per family),
plus the demotion-choice rule (8JZ7 FI7, listed under the boundary class)
which turned out to be a genuine 6th fix: when an atom competes between a
C=C and a C=N double, demote the C=N first.  Per-family resolution:

1. **Crash family (13):** the over-valent crashes are fixed by the
   valence-demotion choices below and the nitro fixup; the kekulize crashes
   by the aromatic-set gates (5-ring exo-double block, short-bond strictness)
   plus the slack-drop retry.  Verified: 6Y4 (5KYA), 9TP (4L9Q), WMJ (3QTX)
   recover exactly.
2. **Nitro valence:** nitro fixup - an N with two terminal O's <= 1.45 A is
   +1 charged with one N=O and no H; non-O doubles are demoted first.
3. **False-positive aromatization (V0X class):** 5-ring O/S rings must carry
   at least one genuine double-length edge not incident to the O/S atom
   (gate 6); pure-carbon and pyridine-type rings stay unchecked.
4. **Phosphate P=O gap:** P with 3+ terminal O's emits one P=O on the
   shortest O plus a -1 charged O(-) - same charge-emission machinery as the
   nitro zwitterion.
5. **Azole/S-ring judge:** 5-ring N with an exo substituent is
   pyridinium-type (1 pi) when the ring holds a second heteroatom (X43);
   S/P exo bonds never block a ring (W5C); thiophene-type C-S in the ring is
   counted as conjugation evidence only when short.

Re-evaluation (new labeled run, `results_heldout_fix.md`): bond-order
recovery by the geometry tier rises from 223/300 (74.3%) to **241/300
(80.3%)** on main and 221/300 (73.7%) to **228/300 (76.0%)** on lowres
(+18 / +7 ligands).  Stereo full-string: main 114/121 (94.2%) -> **122/131
(93.1%)** with the comparable set growing 121 -> 131 (+8 exact graphs is the
fix effect), lowres 103/125 (82.4%) -> **107/129 (82.9%)**.  Per-center R/S
99.5% / 99.8%, E/Z 12/13 main.  openbabel / distance / rdDetermineBonds
columns unchanged (no code change in those tiers).  **Zero regressions** in
any bucket.  Tuning-gate numbers unchanged (89/101 main, 74/101 lowres).

**5 remaining data limitations** (kept out of the strict recovery
assertions, documented in `tests/fixtures/heldout_regression.json` +
`test_perception.py`): 5MUY MGT (ribose enol-C2'), 7FOZ WD0 (N=C 1.172 A in
thiazoline), 5ME6 M7G (charged reference, +16 H vs the CCD zwitterion),
6S7B KYH (ribose), 7T2X EMY (ring-chain ambiguous; see the correction
below).  All degrade gracefully (no crash, sane mol, wrong graph) and are
pinned as such in the regression tests.

**Broken-ring refusal (thiazole fix, narrowed):** a pre-existing synthetic
test failure (thiazole at zero noise: ETKDG seed-42 refines the 5-ring to a
fragment - S-C 1.90 A, C-N 1.16 A) was fixed by refusing a molecule whose
SINGLE ring carries both an over-long edge (beyond envelope + slack) and an
under-short edge (below envelope lo - slack), so the OpenBabel fallback the
corpus reserves for S-heterocycle embeds can rebuild it.  A first version
that refused on the over-long edge alone was measured against the crystal
datasets and rejected: it fires on real low-res ligands (porphyrins HEM/HEC/
ZNH/HEB, nucleotides, 21 entries across the 12 datasets) and cost ~2
recoveries + ~14 AddHs.  Real planar rings stretch at 2.5-3.0 A resolution
but never also compress below ~1.25 A, so the both-directions condition
fits the data: zero crystal entries match it, and the final re-run
reproduces the fix-run sidecars exactly.

## How this was produced

- `heldout_failures.json` - per-failure records: kind (None/formula/graph),
  per/ref SMILES, whether OpenBabel and the distance baseline recovered the
  entry, and an MCS atom-mapped diff signature (bond-order and H diffs vs the
  CCD reference). Generated by `analyze_heldout_failures.py`.
- `heldout_failures_inspect.txt` - the coordinate evidence: every disputed
  bond's measured length from the deposit, plus ring geometry (bond lengths +
  planarity RMS via inertia tensor). Generated by
  `inspect_heldout_failures.py`. Every length cited below comes from this
  file.
- `classify_heldout_failures.py` - the mechanism tally (rule-based tags,
  representative clusters hand-verified against the inspect table).
- Recovery flags are the discriminator: a case OpenBabel (or the distance
  baseline) recovers proves the coordinates support the CCD chemistry, so the
  failure is a perception defect, not a coordinate artifact. Caveat: ob also
  recovers some genuinely ambiguous cases via zwitterionic charge guesses
  (e.g. W9U, long-nitro), so "ob recovers" alone is not proof of a bope bug.

Reproduce from `benchmarks/crystal100`:

```bash
uv run python analyze_heldout_failures.py    # regenerate heldout_failures.json
uv run python inspect_heldout_failures.py    # regenerate heldout_failures_inspect.txt
uv run python classify_heldout_failures.py   # mechanism tally
```

## Genuine bugs - 5 families to fix

### 1. Crashes (13): 6 kekulize + 7 over-valent, 3/13 ob-recoverable

- kekulize: 5MUY MGT, 7RS8 7EI, 2QG0 A94, 5ME6 M7G, 5KYA 6Y4, 5OOB MGT
- over-valent "no double to demote": 7FOZ WD0, 2QES ADE, 4L9Q 9TP, 6S7B KYH,
  5GHV X5G, 1GSF EAA, 7T2X EMY
- 4L9Q 9TP, 5KYA 6Y4, 1GSF EAA are recovered by OpenBabel - the coordinates
  fully support the chemistry, so these are pure perception defects.

Root causes: (a) the aromatic set plus remaining length-rule doubles creates a
pattern SanitizeMol cannot kekulize, with no retry; (b) the length rule
over-assigns a double with no other double to demote (over-valent C/N/O).

Fix direction: (a) when the full aromatic set fails to kekulize, retry without
the slack-admitted rings (the existing slack-drop retry should be extended to
the aromatic-set level) and, as a last resort, return a best-effort
length-rule molecule instead of None; (b) debug the specific over-valent
patterns - they are all recoverable geometry.

### 2. Nitro valence (6+): N=O demoted even at textbook lengths

- 4EK8 16K N=O at 1.214 A, 8BGA at 1.221, 7ENE at 1.179 - all demoted to
  single. 7ENE recovered by ob.
- 6SUH LVE (6-member cluster), 3B67 B67, 2YOH: nitro at 1.36-1.42 A (long,
  low-res); ob recovers via zwitterionic charge assignment - the charge-model
  gap.

Root cause: N vmax=3 cannot hold two N=O; the valence demotion pass destroys
nitro even at perfect geometry.

Fix direction: (a) nitro fixup - an N with two terminal O's at <=1.30 A is a
nitro group: both N=O, N takes no H (exempt from the vmax-3 demotion, treat N
as hypervalent like S); (b) the zwitterion sub-case needs the charge machinery
(see phosphate below) - without it, long nitro at lowres stays ambiguous.

### 3. False-positive aromatization (11): Huckel judge accepts saturated rings

- 5ST6 V0X: 2,3-dihydrobenzofuran 5-ring CCOCC (C-O 1.313/1.380, C-C 1.476/
  1.521, planar 0.017) scored O 2pi + 4C = 6pi and was marked aromatic,
  stripping real hydrogens. ob recovers.
- Same signature (bope makes saturated bonds aromatic, "X 1.0->1.5a"): 1R4U
  OXC, 7R7R AWJ, 6DGL GEV, 1WQW BT5, 5HE2 F0S, 1IL3 7DG, 3DCV 55E, 8GBK HEB,
  2BXT C2D, 6B9U NAI.

Root cause: the Huckel judge accepts rings with no short (C=C-length) edge -
V0X's ring has no bond under ~1.31 other than the C-O's.

Fix direction: require at least one genuine double-length edge (C-C <= 1.40
or C-N/C-O <= 1.35) in a candidate aromatic ring, and/or tighten the C-O
aromatic envelope floor (furan C-O is 1.36-1.38; V0X's 1.313 is in-envelope
but far from furan).

### 4. Phosphate P=O gap (8+): P-H fallback instead of P=O + charge

- 1TPB PGH P-O at 1.701, 2VF5 GLP at 1.591, 2I22 I22 at 1.604 - bope falls
  back to P-H; ob recovers.
- Also: 1BPE DTP (P-H junk cluster), 4EAQ ATM, 2CZF XMP, 4KSY 1SY, plus the
  mixed entries 3U4H C8R, 3LV6 BMP, 1CQ6 PY4, 6VCO APC, 7WQI 80I (the last
  two are ribose-coordinate cases, see below).

Root cause: no charge model. A protonated phosphate P with four P-O singles
is over-valent only for P=O; the geometry alone cannot tell P=O (1.50-1.52)
from P-OH (1.55-1.60) at lowres, and the code has no way to emit P-O(-).

Fix direction: a phosphate rule like the quaternary-N +1 fixup - P with 3+
terminal O's: shortest O becomes P=O, one other becomes P-O(-) with a -1
formal charge. This is the same machinery the long-nitro zwitterion needs.

### 5. Azole / S-ring judge gaps (4+ distinct mechanisms)

- 3QTX X43: N-substituted thiazole, planar 0.010, all bonds in envelope, but
  the exo-substituted ring N is counted pyrrole-type (2 pi) -> 7 pi -> ring
  rejected, falls back to a diene + exo C=N. Fix: in a 5-ring, an N with an
  exo substituent is pyridinium-type (1 pi) when the ring holds a second
  heteroatom (imidazole/thiazole N); pyrrole-type (2 pi) only when it is the
  ring's sole heteroatom (N-methylpyrrole).
- 7FOY W5C: textbook planar (0.002) triazole rejected because the 5-ring
  exo-block rule is vacuous for S: vmax(S)=6 means every C-S <= 1.72 A on a
  5-ring "stays within valence as a double" and blocks the ring. The 1.687 A
  thioether C-S blocked it. ob recovers. Fix: do not block on C-S exo bonds
  (use the thione threshold ~1.68, or exclude S from the block test and let
  the demotion pass fix over-valent S).
- 2XDA JPS: thiophene ring planar 0.002, ob recovers; C-S 1.646 A is 4 mA
  below the slack-adjusted envelope floor (1.66 - 0.01 = 1.65). 5U2E 837 C-S
  1.635/1.654 similar. Boundary case - see the boundary section; a small
  floor move would fix both, but C-S 1.646 is genuinely short for thiophene
  (ideal 1.714), so verify against the tuning set before touching it.

## Threshold-boundary class (~40): shared cutoffs, not per-case tuning

All failures here sit on one shared set of global thresholds; each miss is
0.001-0.05 A from a single cutoff. Loosening any one fixes several cases at
once, but each threshold was set against the tuning set, so every loosen
risks new false positives elsewhere (the V0X class shows the judge is already
too permissive in places). Treat as a threshold-sensitivity paragraph in the
paper, not a fix list.

- Envelope floors/ceilings: 8QIY VCC pyrazole C-N 1.263 (floor 1.28, -0.007
  past slack), 3U4H C8R purine C-N 1.471 (ceiling 1.47, +0.001), 5RUV W6J
  pyridine C=N 1.256 (floor 1.28), 1CQ6 PY4 C=O 1.304 (double cutoff 1.30,
  +0.004), 3C21 2BA P=O 1.515 (P=O cutoff 1.55).
- C=C length rule demoting 1.38-1.47 A bonds: 5E1C 5K8, 1KT7 RTL, 3IMT IW3
  (4x cluster), 6OPU 017, 12PL LMS, 7EJ9 DYX, 4KKO 1RE, 2UXO TAC, 5P9L 7G9,
  3R5M MLO, 5IWD 6EV, 2QN2 0MA, 7LAI R78. Most are ob-recoverable - the
  coordinates support the CCD; the 1.38 C=C cutoff sits inside the density of
  real crystal C=C lengths at lowres.
- Alkyne cutoff: 6FZM EE5 C=C 1.286 vs the 1.26 triple cutoff (ob recovers;
  1.286 is long but a crystal C=C is 1.33+, so 1.29 is a safe cutoff).
- Demotion choice: 8JZ7 FI7 - both C=N (1.327) and C=C (1.361) inside their
  double cutoffs; the demotion pass keeps the shorter (C=N) and demotes the
  C=C, but the 1.361 C-C is the unambiguously-double one (C-C singles never
  refine below ~1.46, while amide C-N singles sit at 1.33-1.36). Candidate
  rule: when an atom competes between a C=C and a C=N double, demote the C=N
  first. Note ob AND dist both fail on 8JZ7, so it is genuinely hard.
- Sulfone: 2O9I 444 (OS 2.0->1.0) - sulfone S=O at lowres.

## Coordinate-bound class (~55): the deposit contradicts the CCD

Verified by direct measurement - no bond of the required length exists
anywhere in the deposit. OpenBabel fails on nearly all of these too. This is
the benchmark's intrinsic floor: crystallographic H4-type residues where the
refined geometry disagrees with the CCD record. Document as a limitations
section, do not tune against them.

- No C=C-length bond exists: MKU prenyl C=C at 1.533 (6-member failure
  cluster!), 4KY2 1W3 1.552, 7HJ 1.519, 7OXB 35Z 1.530, EOL 1.525.
- Ribose C1'-C2' shorter than a single: 6VCO APC 1.309, 7WQI 80I 1.355.
- Tautomer coordinates (deposit refined the other tautomer): 5STO W9U
  oxime-vs-hydroxylamine (C-N 1.276, N-O 1.323 - genuinely oxime-like), 8E9Y
  WE9/8E9X amidine C=N 1.445/1.452, 7T2M EGK/7SVN nitrile C=N 1.259, 3LV6
  BMP uracil C-N 1.486/1.495, 7N44 06I pyridinone C=O 1.384-1.406, 4DPI 0N1 /
  3PD3 A3T / 1FD7 AI1 lactam->enol-imine (C=N 1.258 + C-O 1.304 fit the
  enol-imine better than the lactam).
- Deposit shows a triple the CCD calls single: 7VJL 7IF C-N 1.134, 8U6M VW2
  C-C 1.257 (bope reads these as nitrile/alkyne; the coordinates support it).
- Low-res cyclohexene distortion: 2QN2 0MA, 7LAI R78 (rings rms 0.22-0.25,
  no short edge).

## H-only tautomers (12)

8OV7 W3W, 2F4J VX6, 3KF4 B90, 7FNL VWR, 1ETZ GAS, plus mixed entries
(3DCV 55E, 5ZC5 09I...). Coordinates never record H positions; the graph
matches, only the H distribution differs (NH0<->NH1). ob fails on 10/12.
Unresolvable without H positions - document, do not fix.

## Out of scope

- Metals/other elements (4): 1H9M MOO (MoO), 6LVQ VO4, 9PTR VO4, 1BEH CAC
  (AsO) - the perception targets organic ligands.
- Charge edge cases: 5H5F SAM sulfonium (S-methyl, needs +1), 8A0I CNZ
  (NH3->2), 6LW1 EX3 (CH1->0 x2).

## Follow-up plan (ordered by leverage)

1. Crash family: never return None - retry without slack rings, then
   best-effort length-rule molecule. 3 ob-recoverable crashes are pure wins.
2. Nitro fixup: N with two terminal O's <= 1.30 -> both N=O, no H, exempt
   from vmax-3 demotion.
3. False-positive aromaticity: require a genuine double-length edge in every
   candidate aromatic ring (kills V0X), plus C-O floor check.
4. Charge machinery (P=O phosphate + nitro zwitterion + sulfonium): a small
   charge-emission pass after valence, covering the most common charged
   groups.
5. Azole/S: N-substituted 5-ring N pi-count rule (X43); exclude C-S from the
   5-ring exo-block test (W5C).
6. Demotion choice: prefer demoting C=N over C=C on a competing atom (8JZ7).
7. Boundary sensitivity analysis for the paper: per-threshold error curves
   (envelope floor/ceiling, C=C cutoff, slack values) with tuning-set
   counterexamples for every loosen.

Discipline: each fix in a clearly-separated commit; the held-out numbers in
`results_heldout.md` are never re-measured. If a follow-up benchmark is ever
run after fixes, it is a NEW run with its own results file, labeled as such.
